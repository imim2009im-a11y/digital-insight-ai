# سجل التطوير المستمر

## Cycle 1 — تحسين SEO للمسارات الداخلية

**المشكلة المكتشفة:** كانت جميع المسارات تعتمد على عنوان ووصف عامين من `client/index.html`، مما يضعف وضوح صفحات المفضلة والاقتراح ودليل المحتوى لمحركات البحث والمشاركة.

**التحسين المنفذ:** أُضيف hook قابل لإعادة الاستخدام باسم `usePageMeta` يحدّث عنوان الصفحة ووصفها ووسوم Open Graph والرابط canonical حسب المسار. طُبق على الدليل العام، دليل المحتوى، المفضلة، إضافة أداة، واقتراح أداة.

**الملفات المتأثرة:** `client/src/hooks/usePageMeta.ts`، الصفحات الخمس، و`package.json` لتوسيع نطاق lint.

**الاختبارات:** نجحت Prettier، و`pnpm lint`، و`pnpm test`، و`pnpm check`، و`pnpm build`، و`pnpm audit --prod`. تمت مراجعة الصفحات بصريًا على سطح المكتب.

**النتيجة:** لا توجد أخطاء بناء أو TypeScript أو ثغرات إنتاجية معروفة، مع تحسين قابلية اكتشاف المسارات الداخلية دون إضافة تبعيات أو تغيير سلوك المستخدم.

**Commit / Deployment:** سيُسجّل commit الإصدار بعد المزامنة والنشر.

## Cycle 2 — مقترحة بعد موافقة المستخدم

إضافة اختبارات متصفح آلية لمسارات الاقتراح والمشاركة والثيم، مع التحقق من حالات الفشل والنسخ الاحتياطي للحافظة قبل التفكير في ميزات أكبر أو ربط Backend.
