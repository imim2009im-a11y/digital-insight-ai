# SafeRelay AI

MVP concept for a safe anonymous-feedback and message relay platform.

## Current Status
- Landing page
- Demo inbox page
- Demo dashboard
- Local message analysis in browser
- Terms and Privacy pages

## Not Implemented Yet
- Authentication
- Database
- Real message delivery
- OpenAI moderation API
- Subscriptions
- Admin panel

## Recommended Stack
- Frontend: GitHub Pages / Vercel
- Database: Supabase
- Authentication: Supabase Auth
- AI Moderation: OpenAI Moderation API
- Backend: Edge Functions or Serverless Functions

## Security Note
Never expose API keys in GitHub Pages or frontend code.
