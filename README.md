# Digital Insight AI 🚀

**Digital Insight AI** هو موقع عربي عملي لاكتشاف ومقارنة أدوات الذكاء الاصطناعي للأعمال، التسويق، صناعة المحتوى، الفيديو، وبناء التطبيقات.

الموقع منشور الآن ومتاح للتجربة:

👉 **الموقع الرئيسي:** https://imim2009im-a11y.github.io/digital-insight-ai/

👉 **صفحة الأدوات:** https://imim2009im-a11y.github.io/digital-insight-ai/tools.html

👉 **رابط قصير للنشر:** https://imim2009im-a11y.github.io/digital-insight-ai/go/

---

## حالة الإطلاق

تم إطلاق النسخة الأولية القابلة للاختبار التجاري في **2026-06-10**.

الهدف الحالي ليس الادعاء بتحقيق ربح فوري، بل اختبار:

- اهتمام الزوار بأدوات الذكاء الاصطناعي.
- عدد نقرات روابط الأفلييت.
- عدد رسائل التواصل والاشتراكات.
- أكثر الأدوات جذباً للزوار.

---

## ما يحتويه الموقع

- صفحة رئيسية تعريفية.
- صفحة أدوات ذكاء اصطناعي مصنفة حسب الاستخدام.
- مقالات مقارنة مثل Kling AI vs Runway و Lovable vs v0.
- نموذج تواصل متصل بخدمة Formspree.
- نموذج نشرة بريدية متصل بخدمة Formspree.
- تتبع محلي لنقرات روابط الأفلييت.
- لوحة محلية لمراجعة النقرات.
- سياسة خصوصية وإفصاح أفلييت.
- robots.txt و sitemap.xml لتحسين قابلية الفهرسة.

## خطة أول 7 أيام

المؤشرات المستهدفة:

- 50 زيارة أولية.
- 10 نقرات على روابط الأفلييت.
- 3 رسائل تواصل أو اشتراكات.
- معرفة أكثر 3 أدوات حصلت على اهتمام.

الروتين اليومي:

1. نشر رابط صفحة الأدوات أو الرابط القصير.
2. متابعة رسائل Formspree.
3. مراجعة لوحة النقرات المحلية.
4. تسجيل أكثر أداة جذبت اهتماماً.
5. كتابة مقال جديد بناءً على البيانات، وليس التخمين.
