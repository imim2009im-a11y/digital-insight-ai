# Digital Insight AI

منصة ذكية للحصول على رؤى وتحليلات قيمة باستخدام تقنيات الذكاء الاصطناعي.

## 📋 نظرة عامة

Digital Insight AI هو مشروع ويب حديث يوفر واجهة تفاعلية للمستخدمين للاستفادة من قدرات الذكاء الاصطناعي في تحليل البيانات والحصول على رؤى قابلة للتنفيذ.

## ✨ المميزات

- 🤖 تحليل ذكي للبيانات باستخدام AI
- 📊 لوحة تحكم تفاعلية
- 🎨 واجهة مستخدم حديثة وسهلة الاستخدام
- 📱 متوافق مع الأجهزة المختلفة (Responsive Design)
- ⚡ أداء عالي وسريع

## 🚀 البدء السريع

### المتطلبات

- متصفح ويب حديث (Chrome, Firefox, Safari, Edge)
- اتصال بالإنترنت

### الاستخدام

1. استنسخ المستودع:
```bash
git clone https://github.com/imim2009im-a11y/digital-insight-ai.git
cd digital-insight-ai
```

2. افتح ملف `index.html` في متصفحك:
```bash
# على Linux/Mac
open index.html

# على Windows
start index.html
```

أو استخدم خادم محلي:
```bash
python -m http.server 8000
# ثم افتح http://localhost:8000
```
