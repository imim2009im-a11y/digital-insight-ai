## Research method

These are recommended research sources, NOT an endorsement of every claim. Check the original video, publish date, upstream docs, repo, security, licensing, current pricing before implementation. Where a channel URL is not confidently resolved, use official org/creator links or YouTube channel search; no invented handles.

## Selection and governance
1. Before tracking a new topic, search existing IA code/issues/docs for equivalent open/completed work.
2. Extract from each source: canonical URL, title, publication date, topic, tool/repo, upstream official documentation, price/license, security, applicability to existing project, article potential, service potential, evidence.
3. De-duplicate by canonical source video + tool + use-case across channels.
4. Triage outputs: (A) immediate verification for known blockers, (B) existing project improvement, (C) original article/video, (D) sellable service hypothesis, (E) defer/reject.
5. Never copy script/transcript/media; use attribution and independently test before publishing.
6. No blind installation, production deployment, trading, payments, secrets, privileged device access or automatic publishing.
7. Each week review a manageable high-signal sample and report tested wins, failures, real costs and outcomes. This document is a source list, NOT proof of channel subscription, YouTube API ingestion or continuous monitoring.
